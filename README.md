### 📋 Overview
This lab demonstrates real-world threat detection using Wazuh SIEM. I simulated attacks on Windows and documented how Wazuh detects them.

- **Task 2:** Brute Force / Failed Logins

### 🛠️ Tools Used
Wazuh 4.x, Windows Security Events, Sysmon, Threat Hunting
